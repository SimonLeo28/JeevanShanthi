## 2) Google Search Console Setup

### Step 1: Create a Google Search Console property
1. Go to https://search.google.com/search-console
2. Sign in with the Google account you want to use for the business
3. Add property:
   - Recommended: URL prefix
   - Property URL: https://www.jeevanshanthi.com
4. Verify ownership using one of these methods:
   - HTML tag
   - DNS record
   - Google Analytics / Tag Manager if already connected

### Step 2: Submit sitemap

### Step 3: Verify indexability

Use the "URL Inspection" tool and request indexing for each page.

### Step 4: Check coverage
